# OMSUN Nepal — Empowering Energy

Premium e-commerce web application for **OMSUN Nepal Pvt. Ltd.**, an Electrical, Renewable Energy & Solar Solutions company in Nepal.

The store sells electrical products, solar equipment, industrial electrical components, cables, switches, lighting solutions, panels, and renewable energy products and accessories — delivered through a modern, premium, conversion-focused shopping experience.

## Tech Stack

- **Frontend:** React 19 + TypeScript
- **Framework:** TanStack Start / React Router (file-based routing)
- **Styling:** Tailwind CSS v4
- **Animation:** Framer Motion
- **Components:** Radix UI + shadcn/ui
- **Charts:** Recharts
- **Forms/Validation:** React Hook Form + Zod
- **Icons:** Lucide

## Features

- Cinematic full-screen hero with animated solar robot mascot
- Shop by category, featured products, best sellers & new arrivals
- Trusted brands and partner logos
- Why Choose OMSUN and energy saving benefits
- Company statistics and customer testimonials
- Advanced product details page (gallery, specs table, related products, sticky purchase panel)
- Shop page with filters (category, price, availability, brand), sorting, search and grid/list toggle
- Shopping cart with drawer
- Minimal, fast and premium checkout flow
- Customer dashboard (orders, order tracking, profile, addresses)
- Admin dashboard (analytics, charts, inventory, low stock alerts, orders)
- Fully responsive (desktop-first, tablet + mobile perfected)
- WCAG-friendly, keyboard-navigable and accessible UI

## Getting Started

Prerequisites: **Node.js + npm** ([install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating))

```sh
git clone <this-repository-url>
cd <repository-name>
npm install
npm run dev
```

`npm run dev` starts the Vite development server. Open the URL printed in your terminal to view the app.

## Scripts

| Script              | Description                              |
| ------------------- | ---------------------------------------- |
| `npm run dev`       | Start the development server             |
| `npm run build`     | Build the production bundle              |
| `npm run build:dev` | Build using development mode             |
| `npm run preview`   | Preview the production build             |
| `npm run lint`      | Lint the codebase with ESLint            |
| `npm run format`    | Format source files with Prettier        |
